# Akhil Gajjela — React Portfolio

## Open in VS Code
1. Extract this ZIP file.
2. In VS Code, choose **File → Open Folder** and select `akhil-react-portfolio`.
3. Open the integrated terminal (**Terminal → New Terminal**).
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Add your profile photo
Replace `src/assets/profile.jpg` with your own photo, keeping the exact filename `profile.jpg`.
A placeholder image is included so the project runs immediately.

## Before publishing
Add your actual LinkedIn, GitHub, project repository and live-demo URLs. They were not present in the supplied resume, so this starter does not invent them.
